# Sprint 1 Planning — ERP Django

## Sprint Goal

Diseñar y documentar el modelo entidad-relación del ERP, definiendo sus ocho entidades, atributos, relaciones y decisiones de diseño antes de implementar los modelos en Django.

## Historias de usuario (HU)

| ID | Historia de usuario | Prioridad |
|---|---|---|
| E2-01 | Como administrador, quiero organizar los productos por categorías. | Alta |
| E2-02 | Como administrador, quiero registrar proveedores de productos. | Alta |
| E2-03 | Como usuario, quiero registrar clientes. | Alta |
| E2-04 | Como usuario, quiero registrar productos con precio y existencias. | Alta |
| E2-05 | Como usuario, quiero registrar ventas asociadas a clientes. | Alta |
| E2-06 | Como usuario, quiero registrar los productos y cantidades de cada venta. | Alta |
| E2-07 | Como usuario, quiero registrar pedidos de clientes. | Media |
| E2-08 | Como administrador, quiero configurar los datos generales del ERP. | Media |
